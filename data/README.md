# Data used by AirMind (offline)

- `cedict.txt.gz` - CC-CEDICT Chinese-English dictionary (MDBG, https://www.mdbg.net/chinese/dictionary?page=cc-cedict),
  licensed CC BY-SA 4.0. Release 2023-11-07, taken from the `pycccedict` package.
  To update: download cedict_1_0_ts_utf-8_mdbg.txt.gz from MDBG and save it here as cedict.txt.gz.
- `hsk3.json` - HSK 3.0 (2021) word lists, word -> level (7 = levels 7-9), built from the npm package
  `@leonsilicon/hsk3.0`.
